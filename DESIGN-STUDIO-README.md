# Mauccounting ERP — Designer Studio

A new `Design/` workspace for the public `mauccounting.erp.system` repository.

## Included tools
- **Create Database:** creates `data/<Name>/<Name>.dat` in the private `mauccounting.erp.database` repository and registers the entity in `data/manifest.json` in the same Git commit. Headers are supplied by the administrator.
- **Create Web Interface:** visual drag/drop or click-to-add builder. Components have unique IDs and editable labels/text.
- **Update Interface:** lists HTML files under `Design/generated/` in the public repository. Pages authored by Designer Studio can be re-imported into the visual builder.
- **Create Scripts:** bind a component ID to a sheet and column for display, SUM, COUNT, filter/table output, or a JavaScript formula expression. Scripts are embedded in generated HTML.

## Deployment
1. Back up the current public repository.
2. Upload/merge the complete contents of this ZIP into the root of `mauccounting.erp.system` (keep existing files and folders).
3. Ensure the private repo still has `data/manifest.json` and its entity `.dat` files.
4. Sign in as an Administrator and open **Setup → Designer Studio**.
5. Test Create Database with a temporary sheet and test generated HTML before using production records.

## Repository configuration
`Design/designer.js` uses owner `mau-acc-system`, private repo `mauccounting.erp.database`, public repo `mauccounting.erp.system`, branch `main`. Change these constants if the GitHub owner or branch differs.

## Important limitations / security
- Uses the existing `license.tk` hex-encoded GitHub token. Hex encoding is not encryption; the token is recoverable from a public frontend. Use a narrowly scoped token and rotate it if exposed. A proper server-side proxy or GitHub App is needed for secure production writes.
- GitHub writes require the token to have Contents write access to BOTH repositories (private database and public interface repo).
- Script formulas are JavaScript expressions executed in the generated page. Only trusted administrators should create or edit scripts.
- The builder currently supports basic form/layout controls, basic sheet bindings, SUM, COUNT, simple filter table, and formula expressions. It is not a full visual CSS editor or full application framework.
- The Update Interface import is supported for HTML generated by Designer Studio. Existing arbitrary HTML pages are listed but cannot be converted back to editable components automatically.
- Syntax checked locally; not live-tested against the user's GitHub repositories or token permissions.
